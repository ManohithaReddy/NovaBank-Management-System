

# NovaBank Management System

## Description

NovaBank Management System is a desktop-based banking application developed using Core Java to manage customer banking operations efficiently. The project provides functionalities such as account creation, deposits, withdrawals, balance enquiry, PIN change, and transaction handling through an interactive graphical user interface.

The application uses Java Swing and AWT for frontend GUI development and MySQL as the backend database for storing and managing customer account information securely.


## Features

* User Signup and Login
* Account Creation
* Deposit Money
* Withdraw Money
* Fast Cash Facility
* Balance Enquiry
* PIN Change
* Mini Statement
* Transaction Management
* Secure Database Connectivity

## Project Structure

Login.java → User login functionality
Signup.java → New account registration
Deposit.java → Deposit operations
Withdrawl.java → Withdrawal operations
BalanceEnquiry.java → Account balance checking
FastCash.java → Quick cash withdrawal functionality
MiniStatement.java → Display recent transaction history
Pin.java → PIN change functionality
Conn.java → Database connection handling


## Database

The project uses MySQL to store:

* Account Information
* Transaction Records
* Login Credentials
